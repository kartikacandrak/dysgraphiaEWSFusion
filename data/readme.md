format file:<feature><DB>_<additionalinformation>.npy

<feature>
- online for handcrafted features. 
- offline for deep features. 
- y for target.

<DB>
- DB2
- not mentioned for DB1

<additionalinformation>
Only for <offline>. There are six deep learning backbones that are employed to extract features: Dense201, EfficientNet B7, ResNet50, ConvNeXt, ViT, and Swin Transformer,
